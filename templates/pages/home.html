Flujo de Trabajo y Comandos del Proyecto

1. Servidor Django 
uv run python manage.py runserver

Ejecuta Django en desarrollo con recarga automática.

2. Watcher CSS 
npm run watch:css

Compila Tailwind y DaisyUI en tiempo real al editar templates.

3. Tests y Calidad 
uv run pytest
uv run ruff check .

Garantiza cero regresiones y apego a las reglas de código.
