Modal Dinámico Servidor + Alpine

Este contenido fue solicitado bajo demanda a Django mediante un endpoint HTMX (/htmx/modal-demo/) y renderizado dentro del shell controlado por Alpine.js.

✅ Ventaja Fullstack: Cero JavaScript custom para abrir/cerrar. El ciclo de vida de transiciones y accesibilidad (ESC, backdrop) lo gestiona Alpine; el HTML proviene directamente del servidor Django.

Stack en este componente:

  • Alpine: $dispatch('open-modal')
  • HTMX: hx-get + hx-target
  • DaisyUI: modal-box + alert
